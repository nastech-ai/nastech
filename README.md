# 🧠 NasTech AI

NasTech AI is a futuristic AI assistant platform built on top of the Happy architecture.

Designed to be:
- modular
- voice-capable
- mobile-first
- cloud + local AI compatible
- human-like and intelligent

---

# ✨ Features

## 🤖 Universal AI Providers
Supports:
- Gemini
- Groq
- OpenRouter
- OpenAI
- Anthropic
- Ollama
- llama.cpp

Users can add their own API keys directly inside the app.

---

# 🎤 Voice Assistant
Planned support for:
- realtime voice conversations
- speech-to-text
- text-to-speech
- interruption handling
- multilingual support
- Luganda/local language support

Engines:
- XTTS
- Kokoro TTS
- ElevenLabs
- Whisper.cpp

NasTech is focused on:

# 🌐 Cloudflare Worker API

NasTech includes a universal API gateway using Cloudflare Workers.

Supports:
- provider routing
- secure API forwarding
- universal `/v1/chat`
- mobile connectivity when PC is offline
